
#  Full Stack Authentication App

##  Overview
This is a full-stack web application that provides user authentication using login and signup functionality. The project is built using HTML, CSS, JavaScript for the frontend and Node.js, Express, and MongoDB for the backend.

---

##  Features
- User Signup & Login
- Password hashing using bcrypt
- MongoDB database integration
- Backend API using Express
- Dashboard after login
- Logout functionality

---

##  Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
